# MEMORIA-CHATGPT

Memória persistente de contexto, decisões, estado de projetos e regras de continuidade entre chats.

## Começar um novo chat
Leia primeiro, nesta ordem:
- `INICIO-NOVO-CHAT.md`
- `CONTINUIDADE/OPEN-CHAT-APP-FINALIZACAO-2026-10-11.md` — estado pós-formatação, restauração do Claude Code, CodeJato e sequência de trabalho.
- `ESTADO-ATUAL-OPENCHATCUT.md`
- `PROJETOS/OPENCHATCUT.md`
- `DECISOES/OPENCHATCUT.md`
- `PLANOS/OPENCHATCUT-NEXT.md`
- `PROVEDORES-E-IA.md`
- `HISTORICO/OPENCHATCUT-RECENTE.md`
- `REFERENCIAS-DESIGN/OPENCHATCUT-IMAGENS.md`
- `PREFERENCIAS.md`

Prompt pronto para usar como primeira mensagem: `PROMPTS/PROMPT-INICIAL-OPEN-CHAT-APP-FINALIZACAO.md`.
Depois confira o estado real no GitHub. O computador antigo foi formatado; caminhos e branches registrados antes dessa data são históricos até serem verificados novamente.

## Regra de segurança
Este repositório está público. Não colocar aqui chaves, tokens, senhas, cookies, credenciais ou dados pessoais sensíveis.

## Princípio central
Esta memória existe para evitar que um novo chat reinicie o trabalho:
recuperar contexto -> verificar estado real -> continuar de onde parou.
